## 🛠️ Step 1: Share Insights via Slack

Your merchandise planning team needs to know about the decline you uncovered. Let's share directly from CoWork.

Type:

```
Send a summary of the Home & Kitchen decline findings to the #merch-planning Slack channel, including the top 3 contributing factors and recommended actions
```

<!-- SCREENSHOT: CoWork composing a Slack message -->

CoWork will:
1. Compose a concise message based on your Deep Research findings
2. Show you a preview of what will be sent
3. Ask for your confirmation before sending

**Review the preview** — then confirm to send.

> **MCP Connectors explained:** CoWork uses the Model Context Protocol (MCP) to connect to external tools. Your admin configures which connectors are available. Common options include:
>
> | Connector | Actions |
> |-----------|---------|
> | **Slack** | Send messages, post to channels, share artifacts |
> | **Gmail** | Compose and send emails with data summaries |
> | **Jira** | Create tickets, update issues |
> | **Salesforce** | Log activities, update records |
>
> You don't need to switch apps. The action happens from within your data conversation.

## 🛠️ Step 2: Generate a Buyer Meeting Brief

Your 2pm meeting needs preparation. Ask CoWork:

```
Prepare a buyer meeting brief for my 2pm discussion about Home & Kitchen performance. Include:
- Category performance summary (this month vs last)
- Root cause analysis of the decline
- 3 talking points for the supplier negotiation
- Recommended ask (pricing, delivery timeline, or promotional support)
```

<!-- SCREENSHOT: Buyer meeting brief generated by CoWork -->

CoWork synthesizes everything from your conversation — the metrics from Module 02, the root cause analysis from Module 03 — into a structured brief.

**Save this as an Artifact** for quick reference during the meeting.

> **Try this too:** Ask CoWork to email the brief to yourself:
> ```
> Email this brief to me as a formatted summary I can review on my phone before the meeting
> ```

## 🛠️ Step 3: Create a User Skill

You do this kind of Monday morning analysis every week. Instead of repeating the same questions, let's create a **User Skill** — a reusable multi-step workflow.

Type:

```
Create a skill called "Monday Category Review" that does the following:
1. Pull this week's revenue for Home & Kitchen by subcategory
2. Compare to last week and flag any subcategory that declined more than 10%
3. For any flagged subcategory, identify the top 3 products driving the decline
4. Summarize findings in a bullet-point format ready for my team standup
```

<!-- SCREENSHOT: User Skill creation confirmation -->

CoWork saves this as a reusable skill. Next Monday, you can simply say:

```
Run my Monday Category Review skill
```

And get the same multi-step analysis in seconds.

> **User Skills are personal.** They're saved to your workspace and run with your data access. You can create skills for any repeated workflow:
> - "Weekly supplier scorecard"
> - "Pre-meeting account summary for [customer name]"
> - "End-of-month category close-out report"
